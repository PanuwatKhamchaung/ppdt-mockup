# PPDT Manual

คู่มือระบบจริงภาษาไทยแบบละเอียด อ้างอิงการสำรวจวันที่ 19 พฤศจิกายน 2026

เว็บ: https://panuwatkhamchaung.github.io/ppdt-mockup/manual/

## แก้ไขและสร้างหน้าเว็บ

1. แก้เนื้อหาใน `manual.md`
2. ใส่ภาพที่ผ่านการตรวจข้อมูลส่วนบุคคลใน `assets/`
3. รัน `node build.cjs` จากโฟลเดอร์นี้ (ไม่ต้องติดตั้ง dependency)
4. ตรวจหน้าเว็บก่อน commit

- สารบัญ 20 บท พร้อมค้นหาทั้งชื่อหน้าและเนื้อหา
- สารบัญย่อยในบท ภาพขยาย รองรับคีย์บอร์ด เมนูสำหรับจอเล็ก และพิมพ์ทุกบท
- คู่มืออธิบายระบบจริง ซึ่งอาจต่างจาก demo หน้าแรกของ repository
- บทที่เมนูไม่แสดงในบัญชีที่สำรวจล่าสุดแยกสถานะไว้ชัดเจน
- ไม่รวมรายชื่อผู้ใช้จริง รหัสผ่าน หรือภาพ log ที่มี IP
