Production Control & Production

เลือกเมนู เปิดเคส แล้วทำตามขั้นตอน เทียบผลที่เกิดขึ้นกับผลที่คาดหวัง พร้อมดูภาพประกอบของหน้าที่เกี่ยวข้อง ครอบคลุมเฉพาะ 6 เมนูในสองกลุ่มนี้

Production Control

Data Import → Production Plans → Master Data → Import History
20 เคส · นำเข้า ตรวจแผน ข้อมูลหลัก และประวัตินำเข้า

Production

Operation / CSV → Export History
12 เคส · CSV ย้อนหลัง / Production Plan และประวัติส่งออก
เตรียมก่อนเริ่มทดสอบ และวิธีอ่านผล
  • ใช้สภาพแวดล้อมทดสอบและข้อมูลที่ทีมเตรียมไว้ โดยเฉพาะเคส Import และ Save Master Setup จดค่าเดิมเพื่อคืนข้อมูลหลังจบ
  • T = วันที่ปัจจุบันขณะทดสอบ, D1 = T+1 วัน, D2 = T+2 วัน, D3 = T+3 วัน, Y = ปีของข้อมูลย้อนหลัง ปรับข้อมูลให้มีจริงตามเงื่อนไขของแต่ละเคส
  • เตรียมแผนตัวอย่างที่ทราบ Part, Line, Process และ quantity ทั้ง Main plan / Replenishment พร้อมรายการย้อนหลังที่เคย Export แล้ว และแผนอนาคตที่ยังไม่ Export
  • มีสิทธิ์ใช้งานเมนูที่ทดสอบแล้ว ไม่รวมการทดสอบ Login, User หรือ Role ในหน้านี้
  • เคสทั้งหมดเป็น แบบทดสอบที่จัดทำจากคู่มือ ยังไม่ได้รันทดสอบระบบจริง ข้อที่ระบุ “เกณฑ์ที่เสนอ” ต้องยืนยันกติกากับเจ้าของระบบก่อนตัดสิน Pass/Fail
  • รูปถ่ายหน้าจอเป็นภาพอ้างอิงจากคู่มือ อาจต่างจากรุ่นปัจจุบัน ภาพ History เป็นภาพอธิบายพร้อมข้อมูลสมมติ ภาพไม่ได้เป็นหลักฐานว่าเคสผ่านแล้ว

Pass = ตรงผลคาดหวังทุกข้อ · Fail = พบผลต่างจากเกณฑ์ที่ยืนยันแล้ว · Blocked = ยังไม่มีข้อมูล / เงื่อนไข / เกณฑ์ที่ยืนยันให้ทดสอบ

ผลและบันทึกเก็บเฉพาะเบราว์เซอร์นี้ ไม่ได้ส่งเข้าระบบ PPDT หรือแชร์ให้ทีม กดพิมพ์เพื่อเก็บผลก่อนเปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์

เบราว์เซอร์นี้บันทึกผลถาวรไม่ได้ ผลจะคงอยู่เฉพาะระหว่างเปิดหน้านี้ กรุณาพิมพ์เก็บไว้
